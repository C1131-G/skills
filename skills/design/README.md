# Design

House design languages, written down so an agent builds UI that matches an existing product. Install with `npx skills@latest add C1131-G/skills`.

Every design skill applies `enforce-code-quality`, and `enforce-typescript-strict` for `.ts` / `.tsx`. The full routing table is in [../INDEX.md](../INDEX.md).
